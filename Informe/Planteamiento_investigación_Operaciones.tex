\section{Contexto del Problema}
En el entorno competitivo de la logística urbana, la eficiencia en la "última milla" es crucial para la sostenibilidad financiera y la satisfacción del cliente. La empresa \textbf{Logística Distrital S.A.} enfrenta el reto de distribuir suministros tecnológicos críticos en la ciudad de Bogotá, específicamente en las localidades de Usaquén, Chapinero y Kennedy. 

El problema radica en que la demanda de entregas suele superar la capacidad inmediata, y los tiempos de desplazamiento varían significativamente debido a la infraestructura vial. Se requiere un modelo que permita tomar decisiones informadas sobre la asignación de la flota vehicular para cumplir con compromisos contractuales de entrega mínima mientras se minimizan los costos operativos representados por el tiempo en ruta.

\section{Planteamiento del Problema}
Se deben distribuir paquetes utilizando una flota limitada de \textbf{10 camiones}. La operación se divide en tres zonas principales con características distintas de tiempo y capacidad de entrega. El objetivo principal es determinar la asignación óptima de vehículos que minimice el tiempo total de operación o maximice el beneficio de entregas, garantizando el cumplimiento de las metas mínimas por zona.

\section{Modelo Matemático: Método de la Gran M}
Este modelo busca la optimización global bajo restricciones de desigualdad.

\begin{accentbar}
Variables de Decisión
\end{accentbar}
\begin{itemize}
    \item $x_{i}$: Número de vehículos asignados a la zona $i$ ($i=1,2,3$).
    \item $a_{i}$: Variables artificiales para penalizar el incumplimiento de la demanda mínima.
\end{itemize}

\begin{accentbar}
Función Objetivo
\end{accentbar}
\begin{mathbox}
    \large \textbf{Min } $Z = 60x_{1} + 45x_{2} + 90x_{3} + M(a_{1} + a_{2} + a_{3})$
\end{mathbox}

\begin{accentbar}
Restricciones
\end{accentbar}
\begin{enumerate}
    \item Disponibilidad de flota: $x_{1} + x_{2} + x_{3} \le 10$
    \item Demanda Zona 1: $15x_{1} + a_{1} \ge 45$
    \item Demanda Zona 2: $10x_{2} + a_{2} \ge 30$
    \item Demanda Zona 3: $20x_{3} + a_{3} \ge 60$
    \item No negatividad: $x_{i}, a_{i} \ge 0$
\end{enumerate}

\section{Modelo Matemático: Programación Dinámica}

\begin{accentbar}
Definiciones
\end{accentbar}
\begin{itemize}
    \item \textbf{Etapa (n):} Representa cada zona a la que se le asignarán recursos.
    \item \textbf{Estado ($s_{n}$):} Número de vehículos disponibles para la etapa $n$ y posteriores.
    \item \textbf{Decisión ($x_{n}$):} Vehículos asignados específicamente a la zona $n$.
\end{itemize}

\begin{accentbar}
Ecuación de Recurrencia
\end{accentbar}
Para maximizar el beneficio total (paquetes entregados):
\begin{mathbox}
    $f_{n}(s_{n}) = \max \{ p_{n}(x_{n}) + f_{n+1}(s_{n} - x_{n}) \}$
\end{mathbox}

Sujeto a:
\begin{mathbox}
    $0 \le x_{n} \le s_{n}$
\end{mathbox}
